## Bench data kept outside the repo

Bench working data and human labels may live in `~/.local/share/replay-bench-data/` or `~/.local/share/review-bench-data/`, outside any checkout.

- If either directory exists, read every `README.txt` under it before using anything in it.
- Check there before asking the engineer to relabel units or re-collect candidates.
