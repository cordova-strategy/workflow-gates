Rule under test. This bullet replaces CLAUDE.md §Durable text's "Don't restate the code" bullet for this session:

- **Don't restate the code.** A comment or docstring states only the non-obvious design decisions behind its subject, each naming what was decided and giving a reason static analysis cannot find: why it is this way, or what outside this repository forces it. Delete every other clause, including anything static analysis of this repository's code and tests, or the standard library, finds, even if it is true and takes several files to find. A pointer to the doc or symbol that holds a decision stays. A feature doc states what it does for its user and how to use it, not how it works. Delete a restatement: a shorter or corrected restatement still restates. Naming what a kept decision decides is not a restatement.
